# AP Japanese Studio Patreon QA Checklist

各項目を確認してから、記事を `ready-for-review` と判断します。該当しない項目には理由を記録します。

## 読者と目的

- [ ] 学習者向け、教育者向け、または両方向けかが明確
- [ ] 記事でできるようになることが一つに絞られている
- [ ] APとの関係を誇張していない
- [ ] 公式問題の複製ではなく、オリジナル教材になっている

## 内容の質

- [ ] 冒頭で学生の不安や迷いに自然に寄り添っている
- [ ] 教室や学習現場の具体例が一つ以上ある
- [ ] 説明だけでなく、読者が試せる行動がある
- [ ] 理由、具体例、文化的なつながりが区別されている
- [ ] 日本文化や人々を広く決めつけていない
- [ ] Model responseが丸暗記用ではなく、考え方を示している
- [ ] 間違いから立て直す方法がある
- [ ] 事実、日付、制度、試験情報を一次資料で確認した

## 言語と口調

- [ ] 断定しすぎず、内容に合う慎重な表現を使っている
- [ ] 日本語で読者を「あなた」と呼んでいない
- [ ] 「みんな」「みなさん」または自然な主語省略を使っている
- [ ] 英語もやさしく、押しつけのない口調になっている
- [ ] AIのように同じ長さ・同じ型の文章が続いていない
- [ ] 一文が長すぎず、一度で意味を取れる
- [ ] 漢字レベルが `beginner`、`intermediate`、`AP-ready` のどれかに記録されている
- [ ] 難語には必要に応じて言い換え、文脈、英語説明がある
- [ ] 誤字、文法、句読点、日英の意味のずれを確認した

## 体裁

- [ ] 小見出しは短く、PatreonではHeading 3になっている
- [ ] 小見出しの前後に適切な改行がある
- [ ] Bullet Pointが手入力の記号ではなく、リスト機能で整えられている
- [ ] BoldとItalicは意味を助ける範囲に留めている
- [ ] スマートフォンでも長い文字の壁にならない
- [ ] PaywallがBullet Pointや一つの説明を途中で切っていない
- [ ] 無料部分だけでも有用な学びが一つある

## TierとAudience

- [ ] Studio Supporter / AP Japanese Achiever / Educator Studioの現行Tierだけを使っている
- [ ] 価格表記が必要な場合は $2 / $5 / $10 と一致している
- [ ] AP Japanese Achiever向け記事をEducator Studioも読める
- [ ] 教育者専用素材のAudienceが適切
- [ ] 無料記事はAnyoneになっている
- [ ] 廃止済みのExplorerなどの名称が残っていない

## 画像

- [ ] 記事内容が小さい表示でも分かる
- [ ] 一枚の主なモチーフが一つに絞られている
- [ ] パステルで手描き風、過度な光沢やAI感がない
- [ ] 文字の綴りと日本語表記が正確
- [ ] 手、顔、小物、影、文字に生成破綻がない
- [ ] 不要なロゴ、透かし、著作権キャラクターがない
- [ ] 個人情報、学生情報、位置情報が写っていない
- [ ] 承認済み配色とファイル名ルールに合っている

## Tagsと記録

- [ ] Tagsは `TAG_TAXONOMY.md` から3〜5個選んだ
- [ ] 同義の新規タグを重複作成していない
- [ ] Title、Audience、Access、Kanji level、Sources、Thumbnailを記録した
- [ ] 公開用本文と画像の最終版をGitHubへ保管した

## 著作権とプライバシー

- [ ] 外部教材、問題、Rubric、画像を転載していない
- [ ] 引用が必要な場合は短く、目的に必要な範囲で出典を示した
- [ ] 個人名、メール、学生データ、ログイン情報、非公開URLがない
- [ ] ファイルのメタデータや画面写真に個人情報がない
- [ ] 公開リポジトリに秘密情報を置いていない

## 最終操作

- [ ] PatreonのPreviewでタイトル、画像、改行、Paywallを確認した
- [ ] TagsとAudienceをもう一度確認した
- [ ] Save / Update / Publishの直前でユーザーへ確認した
- [ ] ユーザーの明確な承認後にのみ最終ボタンを押した

## 判定

- **Ready:** 重大な未確認項目がない
- **Needs revision:** 内容、言語、Audience、著作権、プライバシー、画像に未確認がある
- **Blocked:** MFA、ログイン、権限、出典確認、またはユーザー判断が必要
